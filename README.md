# Streamlit QR Code Generator

A simple Streamlit web application that generates QR codes for any text or URL entered by the user. 

## Features

- **Generate QR Codes:** Instantly create QR codes for any text string or URL.
- **Session History:** The app maintains a history of the QR codes you generate during your active session, displaying them in a convenient grid.
- **Download Capability:** Easily download the generated QR codes as JPEG images to your local machine.
- **Interactive UI:** Features a streamed welcome message and a clean, user-friendly interface powered by Streamlit.

## Requirements

The application requires Python and the following packages:
- `streamlit`
- `qrcode`

These are listed in the `requirements.txt` file.

## Usage

The application is deployed and can be accessed directly at: [https://pyqrcodegen.streamlit.app/](https://pyqrcodegen.streamlit.app/)

## Development and Contributions

If you would like to make improvements or run the application locally, you can fork this repository.

1. Fork the repository on GitHub.
2. Clone your forked repository to your local machine:
   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_FORKED_REPO_NAME.git
   cd YOUR_FORKED_REPO_NAME
   ```
3. (Optional but recommended) Create and activate a virtual environment.
4. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
5. Run the application locally:
   ```bash
   streamlit run streamlit_QR_app.py
   ```
